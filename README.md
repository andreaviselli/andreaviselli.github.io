# Andrea Viselli

Personal academic website built with [Hugo](https://gohugo.io/) and the LoveIt theme. I improved the original website layout and home page with the help of AI agents.

The site currently includes research updates, blog posts, ITNOW nowcasting material, and ETS4, an AI-assisted review system for economic forecasting research.
