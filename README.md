# Andrea Viselli

Personal academic website built with [Hugo](https://gohugo.io/) and the LoveIt theme. I improved the original website layout and home page with the help of AI agents.

The site currently includes research updates, blog posts, ITNOW nowcasting material, and ETS4, an AI-assisted review system for economic forecasting research.

Theme credit: [LoveIt](https://github.com/dillonzq/LoveIt), created by [Dillon](https://dillonzq.com/), licensed under MIT.

## Local preview

This site is built and deployed with Hugo Extended 0.114.0. On this computer, the matching binary is installed at `~/.local/bin/hugo-0.114.0`.

Run `./scripts/preview.sh` from the repository, then open <http://localhost:1313/>. Hugo reloads the page as you edit. If port 1313 is already in use, run `PORT=1314 ./scripts/preview.sh` and open <http://localhost:1314/>. To use another compatible binary, run `HUGO_BIN=/path/to/hugo ./scripts/preview.sh`.
